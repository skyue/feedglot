Roadmap

Planned

  • Add subscriptions from the share sheet
  • Navigate to the previous or next article from the reader
  • Include the Feedglot announcements RSS feed on first install
  • Add more fields and layout options to improve reading
  • Export articles as PDF

Under consideration

  • Read articles aloud
  • Pull down in the reader to load Reader View
  • Offer built-in DeepSeek translation without requiring a personal API key

Completed

  • Support iPhone Duo (v1.2.2 build 112)
  • CLI access for agents (v1.2.0 build 110)
  • Zoomable image previews and video playback (v1.1.1 build 104)
  • Restore reading position when reopening articles (v1.1.1)
  • Keep the iOS screen awake during feed refresh (v1.1.1)
  • Set a feed to always use Reader View directly from an article (v1.1.1)
  • Mark articles above as read
  • Sync update times across platforms
  • Share articles as cards
  • Improve performance and consistency across devices
  • Manage subscriptions in bulk
